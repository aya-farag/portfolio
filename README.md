# Aya Farag Badreldeen — Data Analyst Portfolio

A responsive HTML/CSS/JavaScript portfolio built from the supplied CV and dashboard/project images.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive visual design
- `script.js` — mobile navigation + scroll reveal
- `assets/` — profile photo and dashboard screenshots

## Run locally
Open `index.html` in a browser.

## Publish online
Upload the whole folder to GitHub and enable GitHub Pages, or deploy it to Netlify/Vercel.
